# Gfood Self-Service — Redesign 2026

Sistema moderno de autoatendimento para restaurantes self-service integrado ao ecossistema Gfood.

## Funcionalidades

* Pesagem automática
* Identificação de comanda
* Impressão automática
* Painel administrativo
* Integração com Gfood
* Interface moderna em Glassmorphism
* Layout responsivo
* Navegação fluida entre telas

---

## Preview

O sistema simula:

* Tela inicial do totem
* Identificação da comanda
* Captura de peso
* Cálculo automático
* Confirmação do pedido
* Impressão da comanda
* Dashboard administrativo

---

## Como executar

Clone o projeto:

```bash
git clone https://github.com/SEUUSUARIO/gfood-selfservice.git
```

Entre na pasta:

```bash
cd gfood-selfservice
```

Abra o arquivo:

```bash
index.html
```
